Configure in Settings

Choose exactly which models show the panel. Contacts are enabled after install — add Sales, CRM, Projects, or any other model anytime.

  • Open Settings → General Settings
  • Find the Quick Sticky Notes block
  • Select enabled models and Save
  • The panel appears on those form views only

My Notes & All Notes

Review everything in one place, then jump back to the related record in one click.

  • My Notes — notes you authored
  • All Notes — your notes + shared notes you can see
  • Filter by pinned, private/shared, author, or model
  • Open the related Contact / document instantly

How to use (2 minutes)

1. Install Quick Sticky Notes
Update the Apps list and install the free app.
2. Enable models
Settings → General Settings → Quick Sticky Notes → select models (Contacts is enabled by default).
3. Open a saved record
Example: Contacts → open a company/person form (must be saved first).
4. Add a sticky note
Use the Sticky Notes panel → + → write note → choose color / private-shared / pin → Save.

Tip: create notes from the record panel. The My Notes menu is for reviewing existing notes.
